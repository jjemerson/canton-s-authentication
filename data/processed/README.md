# data/processed/

Holds every derived intermediate produced by stages 2 through 5:
extracted euchromatin FASTA (stage 2), Jellyfish k-mer counts and
singleton k-mer lists (stage 3), the pairwise Mash distance matrix
`distances.tsv` (stage 4), and stage 5's per-pair alignment output --
`*.calls.txt` (stage 7's input), `*.sorted.paf` and `*.vcf` (standard
alignment/variant data formats) -- plus the saved neighbor-joining tree
object (`nj_tree.rds`, written by stage 6 alongside its figure).
Human-readable per-pair alignment reports (`*.stats`) live in
`output/reports/` instead; see its own README.

Not version-controlled; entirely regenerated by running the pipeline.
See the top-level README's Methods section for the full derivation
chain.
