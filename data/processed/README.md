# data/processed/

Holds the derived intermediates produced by stages 2 through 5: extracted euchromatin FASTA (stage 2), singleton k-mer lists (stage 3; the Jellyfish count databases are temporary and deleted once dumped), the pairwise Mash distance matrix `distances.tsv` (stage 4), and stage 5's per-pair alignment output -- `*.calls.txt` (stage 7's input), `*.sorted.paf` and `*.vcf` (standard alignment/variant data formats). Human-readable per-pair alignment reports (`*.stats`) live in `output/reports/` instead, and the saved neighbor-joining tree object (`nj_tree.rds`) is written by stage 6 to `output/figures/` alongside its figure; see those directories' READMEs.

Not version-controlled; entirely regenerated by running the pipeline.
See the top-level README's Methods section for the full derivation
chain.
