# data/

Container for pipeline input and intermediate data, split into two
subdirectories: `raw/` (as-downloaded genome assemblies) and
`processed/` (every derived intermediate -- extracted euchromatin,
k-mer counts, distance matrices, alignment calls). See each
subdirectory's own README for specifics.

Not version-controlled (see `.gitignore`); entirely regenerated by
running the pipeline. See the top-level README's Methods section for
what populates each subdirectory and which stage script is
responsible.
