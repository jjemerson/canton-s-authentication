# output/reports/

Holds `*.stats`, one per pair from stage 5 (`50_align_pi.sh`) --
a plain-text summary of that pair's alignment (bases covered,
substitution count, indel counts by size class). Human-readable, and
distinct from `data/processed/`'s `*.sorted.paf`/`*.vcf` for the same
pair, which are standard alignment/variant data formats rather than
summaries of them.

Not version-controlled; entirely regenerated by running the pipeline.
