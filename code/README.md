# code/

Container for this repo's code, split into four subdirectories:
`scripts/` (the numbered pipeline stage scripts, the orchestrator, and
the environment bootstrap), `analysis/` (the R/Python analysis and
figure-generation code the stage scripts call), `src/` (reusable
command-line tools, e.g. the liftover tool stage 2 calls), and `bin/`
(unused -- see its own README). See each subdirectory's own README for
specifics.
