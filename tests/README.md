# tests/

Generic test location from this project's standard directory scaffold.
This pipeline has no automated test suite, and no exposed,
user-runnable verification procedure -- correctness has been
spot-checked during development (clean-clone reruns compared against
known-good output), but that's ad hoc verification, not a repeatable
test target a reader can invoke themselves. For a typical reader, the
practical check is running the pipeline and comparing the result
against the manuscript's figures. Safe to ignore.
